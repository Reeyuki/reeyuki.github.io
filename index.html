YukiOS

A browser-based desktop environment running in a single web page with windowed multitasking, persistent storage, emulators, and 80+ built-in applications.

  • Draggable, resizable windows with snapping, workspaces, and focus cycling
  • File explorer with persistent IndexedDB storage and drag-and-drop from host OS
  • Built-in terminal, code editor (Monaco), dev tools, and command palette
  • Emulators for Flash (Ruffle), DOS (JsDos), console (EmulatorJS), and x86
  • Theme system with 40 presets, animated wallpapers, and Vanta.js support
  • 80+ apps including games, media tools, web apps, and Steam-like game launcher
